# 失败后的重试与恢复检查

2026-10-27。原则：上次权限、配置或状态探测失败不能成为永久禁用操作的依据；用户重试时由真实接口重新检查并反馈错误。保留真实运行中的互斥、身份鉴权、路径边界与必要参数校验。

已修复：

- 漫画/小说刷新：移除目录 `configured=false` 对刷新按钮的禁用；后端每次重新只读检查目录权限，失败不预占任务、不开始库写入，返回实际路径和错误。后台任务通过 defer 释放运行状态。
- 本地阅读/封面：不再把数据库中上次扫描的 `available=false` 当成永久拒绝读取的依据；仍检查当前库根目录及安全路径，实际打开文件时确定是否可读。文件状态文案说明是上次扫描结果。
- 音乐刷新：不再因状态接口失败或尚未返回而禁用手动刷新。
- 漫画 Cookie：读取保存状态失败不会阻止用户填写和保存新凭据；不自动覆盖或新增任何凭据。
- STRM/刮削设置：配置读取失败增加“重新读取配置”，保留未读取成功时不能用空白默认值保存的保护。
- 115 目录选择：增加“重新读取目录”；当前非根目录不再因为上次列表错误而不能选择，实际保存/执行仍由后端验证。
- 媒体处理：去掉前端依据旧 `configured` 状态禁用执行按钮的逻辑，由后端按当前配置验证，缺配置时返回明确错误；运行中仍防止重复触发。
- 影视探索：来源选项不再因旧探测失败被禁用；重试同时强制重新读取来源能力和真实结果，不再仅重跑被旧能力状态挡住的效果。

已检查、已有恢复入口：通用 SettingsForm 的“重新加载”、登录页的“重新连接”、阅读器的重试与图片重载。未移除未填写必填参数、未选择作品、分页边界或尚不支持格式等结构性限制。

验证不运行漫画刷新/导入/清理，不创建测试数据库或改动账号、配置、订阅。目录权限恢复回归测试使用内存文件系统模拟拒绝/恢复和临时空目录。前端类型、测试、构建与本地真实页面只读验证分别记录；NAS 权限和容器部署状态需更新到该版本后在 NAS 验证，不能用本地结果替代。

本地结果：权限恢复及扫描失败回归测试通过，34 项前端测试和生产构建通过；真实 5174 漫画页在后端明确报告 `D:\tmp\res\comics` 不存在时仍显示可操作的“刷新库”，并显示实际目录错误及重试提示。没有点击漫画刷新或业务执行按钮。NAS 尚未发布此修复。
