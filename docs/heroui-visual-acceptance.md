# HeroUI 迁移后的真实页面视觉验收

日期：2026-10-27。使用真实 `http://127.0.0.1:5174` 和 `http://127.0.0.1:18080`、项目现有 `data/`；浏览器已登录真实管理员会话。没有使用模拟响应或演示模式代替真实业务页面。音乐页本身仍是产品已有的演示曲库。

## 本轮发现并修正

1. **整页空白**：`Toast.Provider` 被错误地包在 App 外面；按 MCP 官方示例改为独立挂载 `<Toast.Provider />`。修复后登录页和全部导航页面恢复渲染。
2. **登录复选框文字错行**：旧登录 label 的纵向样式影响 Checkbox.Content，现限定为横向、居中对齐。
3. **设置开关居中**：Switch 根组件默认列方向与旧样式叠加，把开关放到表单中间；现按表单左侧对齐。
4. **设置分类标签折行**：调整公共筛选标签宽度与不换行规则，标签完整显示。
5. **窄屏封面按钮越出网格列**：HeroUI Button 保留固有宽度，390px 视口中 169px 的列被 204px 卡片撑出；现限制按钮为列宽。实测 document.scrollWidth 与 viewport 均为 390，卡片宽 169。
6. **Emby 海报链接撑宽页面**：Link 固有宽度影响网格；现限制为所在网格列宽。
7. **菜单搜索组件属性警告**：ComboBox.InputGroup 缺少官方组合中的 ComboBox.Trigger，导致内部集合属性传到 Input；已补齐 Trigger。重新加载后的最新控制台未再出现该警告。
8. **菜单搜索双重边框、选后不关闭**：由 InputGroup 管理焦点边框；移除强制 selectedKey=null 的状态，让 ComboBox 维护选中项并同步显示标签。已实际输入、选择并确认 aria-expanded=false，路由正确跳转。

## 证据和边界

### 全局去除焦点蓝框（用户最终要求，2026-10-27）

新增全局 focus.css，在入口最后加载，统一去除原生 outline、HeroUI/Tailwind 外圈及输入框的聚焦蓝色边框，包括鼠标和键盘焦点状态；取代此前“键盘保留蓝色封面矩形框”的规则，原有选中底色和普通控件阴影保留。实际搜索输入框点击后 outline none、无蓝色 ring；Tab 到搜索按钮仍为 outline none、ring shadow 透明；排序下拉打开/关闭正常。截图 `tmp/ui-fixes-20261027/global-no-focus-ring.png`，本轮未刷新或修改业务数据。

### 封面焦点样式（2026-10-27）

封面 Button 不再继承普通按钮的胶囊圆角、灰色 hover 底和悬浮阴影。鼠标点击并关闭详情后，实际计算样式为透明背景、outline none、box-shadow none；封面不出现椭圆蓝圈。通过 Shift+Tab / Tab 实测键盘仍获得沿封面 10px 圆角的矩形焦点提示。修复仅作用于 `.poster-card.button`，未全局移除按钮焦点。截图：`tmp/ui-fixes-20261027/comic-card-no-ring.png`；本轮未刷新书库、消费下载文件或改变业务数据。
