# MediaHub HeroUI 前端

使用现有 Go 后端的独立 React / HeroUI 前端。默认显示服务登录；首次部署可直接创建管理员，不再依赖旧前端初始化。

```powershell
pnpm --dir hero install --frozen-lockfile
pnpm --dir hero dev
```

开发地址为 `http://127.0.0.1:5174`，`/api` 代理到 `http://127.0.0.1:18080`。生产构建运行 `pnpm --dir hero build`，将 `hero/dist` 交给现有后端静态文件服务即可。Docker 默认构建 `hero/`；旧 `web/` 作为历史实现保留。

后端在另一个终端运行 `api/scripts/dev.ps1`，使用仓库根目录的 `data`。如需连接其他本地端口，在启动前设置 `VITE_API_PROXY_TARGET`；该变量只控制开发代理。

导航保留原版 8 个入口，并新增「漫文书库」，提供漫画 / 小说两个 Tab。下载记录、影视整理不设独立菜单；全局设置沿用原版 7 个分类。交互对照记录见 [迁移对照](./PARITY.md)。书库目录配置见 [漫文书库](../docs/reading-library.md)。

## 验证

```powershell
pnpm --dir hero typecheck
pnpm --dir hero test
pnpm --dir hero build
```

测试覆盖缓存、授权错误、搜索配置与结果收集、演示网络隔离、分享文件参数、下载恢复、动漫源与自动下载、整理预览 / 执行边界、设置 / 密钥 / 日志契约。

真实 HTTP 联调使用独立数据目录与端口 18081，禁止指向现有数据库：

```powershell
# 在 api 目录的独立终端中启动测试后端
$env:HTTP_ADDR = '127.0.0.1:18081'
$env:MEDIAHUB_DATA_DIR = Join-Path $PWD '../tmp/hero-integration'
./scripts/dev.ps1

# 在仓库根目录的另一个终端中执行
pnpm --dir hero test:backend

# 可选：同时检查真实公开 Bangumi / Mikan / RSS 上游
$env:MEDIAHUB_CHECK_UPSTREAMS = '1'
pnpm --dir hero test:backend
```

脚本只允许 `127.0.0.1:18081`，在该测试库创建测试管理员，验证设置与凭据脱敏、电视剧增改删、动漫保存与自动归类、API 密钥边界、账号修改与会话轮换、日志、下载与整理接口的失败边界。可选上游检查覆盖 Bangumi 探索 / 详情及 Mikan 搜索 / 字幕组 / 元数据解析 / RSS 预览，不提交下载或文件整理。

2026-10-15 已完成 15 组真实 HTTP 联调、21 项前端回归、Go 全量测试及构建。真实 115 文件转存和整理执行需要已有账号登录及有效的 115 配置；联调脚本不会触碰现有账号中的文件。

演示模式仅在浏览器保存订阅、规则和演示任务，不访问服务端管理接口。Emby、115 文件浏览、真实下载 / 整理和外部 RSS 解析需要可用的后端与对应配置。通知页面保存现有后端的配置字段；不为后端尚未实现的通知传输逻辑添加虚假成功反馈。

原 Dashboard 样式原型仍可通过 `/?template=dashboard` 查看。
