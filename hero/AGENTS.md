# 当前前端组件规范

- `hero/` 是唯一维护的前端；`../web/` 已放弃维护，仅作历史参考。
- 使用 HeroUI 前先通过 `@heroui/react-mcp` 的 `list_components` 核对组件名，再用 `get_component_docs` 获取用法；安装和样式规则用 `get_docs` 查询。版本以当前依赖和锁文件为准，不混用 v2 API。
- HeroUI 已提供的交互基础组件直接使用；重复业务参数通过 `components/ui/` 中的包装组件统一，不能另造原生下拉、按钮、开关、表格或弹层。
- 自定义业务布局可以组合 HeroUI 组件。确实没有对应组件时，先核对 MCP 列表，记录自定义原因和设计依据；官方 Figma 无法读取时必须注明，不能声称已核对设计稿。
- 控件改动逐文件审查事件、禁用状态、标签和布局；构建、测试与真实页面视觉验证分开记录，不把编译成功当作页面验收。
- `docs/heroui-component-audit.md` 记录自定义组件与公共包装层；新增自定义组件应同步更新。
